## Project Description

The Personal Task Manager is a simple Laravel project that helps users manage their tasks.

Users can add, view, edit, and delete tasks. They can also set the task status and due date.

## Features

- Add a new task
- View task details
- Edit a task
- Delete a task
- Set task status to Pending or Completed
- Set a due date
- Task validation
- SQLite database

## Technologies Used

- Laravel
- PHP
- SQLite
- Blade
- HTML
- CSS

## How to Run

1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Run:

php artisan serve

4. Open the browser.
5. Go to:

http://127.0.0.1:8000/tasks

The project uses:

Routes → Controller → Model → Database → Blade
